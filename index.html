🌲 Structure & Libellé (navigation sélectionnée ci-dessus)

Par défaut, le widget affiche la table liée nativement à ce widget dans Grist (choisie via le sélecteur de données du widget personnalisé — pas ici). Laissez ce champ vide dans la grande majorité des cas.
Ne renseignez un nom de table que si CETTE navigation doit afficher une autre table que celle liée par défaut. Attention : les données de cette table alternative ne se rafraîchissent pas automatiquement si elles changent dans Grist — un enregistrement du paramétrage ou un rechargement du widget est alors nécessaire.
Saisissez le nom exact de la colonne (respectez la casse), tel qu'il apparaît dans Grist.
Doit correspondre exactement au séparateur utilisé dans la formule Grist qui construit la colonne chemin (ex: "-" ou "§").
Formattez l'affichage avec $colonne (ex: $Code + " -- " + $Libelle).

🖼️ Table d'icônes PNG (commune à toutes les navigations)

Table contenant 2 colonnes : "Nom" (Texte) et "Fichier" (Pièce jointe PNG).
Nom exact dans la colonne "Nom" de la table d'icônes.
Largeur/hauteur des icônes dans l'arbre. Valeur par défaut : 30.
Même principe que la formule de libellé : utilisez $colonne et une expression conditionnelle qui renvoie un nom d'icône (celui de la colonne "Nom" de la table d'icônes).
Comparaisons possibles : égalité (===), différence (!==), supérieur/inférieur (>, <), non null ($Col !== ""), null ($Col === ""), commence par ($Col.startsWith("...")), combinaisons avec && / ||.
Exemple : $Departement === "Ain" ? "icone1.png" : $Code_DGER === "" ? "sans_code.png" : "icone2.png"
Format : niveau=NomIcone (ex: 1=racine.png).
